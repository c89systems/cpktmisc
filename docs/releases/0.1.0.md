# cpktmisc 0.1.0

The first independent cpktmisc release provides static/shared libraries, C89
public headers, CMake packages, pkg-config metadata, examples and third-party
notices. It requires the separately installed **cpkt 0.2.0 SDK for the same
target**, with the exact package identity pinned in `dependencies/cpkt.json`.
cpktdb is independent and is not required.

Pins and checksums are declared in `CMakeLists.txt` and the dependency recipes.
The component inventory records the redistribution scope, notices and patches.
Core libraries used by misc, including zlib, OpenSSL, libxml2, curl and Lua,
remain in the core installation. Their versions come from its validated manifest.
cmocka and libpslog are test prerequisites; libpslog is not shipped. GNU runtime
archives required by the Linux speech stack ship with their notices. Darwin
uses the system libc++ runtime. Speech models are acquired explicitly and are
not release payloads. LZO is GPL-2.0-or-later; the project MIT license does not
replace dependency licenses.

## Consumer contract

Keep core and misc in separate installation prefixes. Use
`CMAKE_PREFIX_PATH="/opt/cpktmisc;/opt/cpkt"`, or
`PKG_CONFIG_PATH=/opt/cpktmisc/lib/pkgconfig:/opt/cpkt/lib/pkgconfig`.
For cross CMake consumers, also add both prefixes to `CMAKE_FIND_ROOT_PATH` and
retain package discovery mode `ONLY`. Use imported targets or pkg-config
`--static` to obtain the required link closure.

The complete codec/archive/foreign-call facades include public types, callbacks,
variables, constants, advanced and deprecated operations. Full-width integer
values use C89 two-word records. Ownership, error behavior, streaming and adapted
records are described in [the facade contract](https://github.com/c89systems/cpktmisc/blob/v0.1.0/docs/compression-facades.md) and
public-header comments. Active liblzma streams must not be copied; call
`cpkt_lzma_lzma_end` to release their private state. Audio and speech support
their documented facade APIs; direct upstream whisper.cpp/ggml compatibility is
outside that support commitment. External-program archive filters retain their
upstream executable requirements.

Audio capture keeps queued frames intact and drops excess incoming frames on
overrun. Native playback drain uses ring state and backend latency; independent
process handles keep pipe descriptors private. File URLs use libcurl's URL parser
and incremental file decoding, with no full-input materialization.
Network MP3 decoding retains partial frames and its native bit reservoir, uses
the file decoder's resampling and gapless metadata semantics, and skips ID3 tags incrementally. VOX
prebuffer capacity reserves room for the minimum speech duration within storage
and time caps. Example dump directories retain existing caller files.
A stopped native playback handle reports an error when drain cannot consume
queued frames, rather than waiting indefinitely.
Playback timing retains its final latency allowance across producer gaps.
Continuous microphone transcription uses the same default 7000 ms segment
budget as decoder input; simplex mode remains uncapped when its budget is zero.
Transcript joining preserves existing leading whitespace.
The CLI forwards prebuffer settings consistently for file, URL and capture input.
Capture retains its transcriber across segments, preserving selected prompt context
and emitting only new transcript text; disabling context is honored for all inputs.
Forward URL seeks discard skipped bytes incrementally within the rewind window.
Restarted native playback retains queued-frame latency accounting. PTT release
and flush emit the release transition even after an exact duration hard cut.
VOX release tracking survives segment hard cuts and trailing silence; CLI
argument parsing preserves the selected disabled-context setting.

This is the first published misc ABI baseline. Facade ABI majors are 0 and are
independent of the release version.

## Artifacts

The release inventory contains seven SDK tarballs: x86_64, aarch64 and armhf
Linux, each GNU and musl, plus arm64 Darwin. It also contains the Darwin smoke
ZIP and the source tarball. `cpktmisc-0.1.0-CHECKSUMS` lists every payload and
ships alongside them. Darwin smoke execution additionally needs the pinned core
libraries on the runtime search path.
